Formula #OS-04

Multi-Level Paging Addressing

Virtual address division across $k$ page table levels with offset $d = \log_2(\text{page size})$.

VA = [ p₁ | p₂ | ... | pₖ | offset d ]
Size = (2^v / PageSize) × PTE_size

Formula #OS-07

Effective Access Time (EAT)

TLB hit ratio $h$, TLB lookup time $t$, and main memory access latency $m$.

EAT = h·(t + m) + (1 − h)·(t + 2m)
With k-level: (1 − h)·(t + (k+1)·m)
High Yield (Annual) GATE '24, '22, '20
Formula #OS-12

SCAN & LOOK Head Traversal

Elevator algorithm path distance where head sweeps cylinder bounds $[0, N-1]$.

SCAN = (Max_cylinder − Initial) + (Max − Min_req)
LOOK: substitutes boundary with extremes
Moderate Yield GATE '21, '18

Formula #CN-02

Sliding Window Efficiency ($\eta$)

Utilization ratio for window $W_s$ where $a = T_p / T_t$. Stop-and-Wait uses $W_s = 1$.

η = W_s / (1 + 2a) where a = (Distance/v) / (L/B)
Optimal Window W* = 1 + 2a
High Yield (6 Yrs) GATE '23, '22, '19
Formula #CN-08

CIDR Usable Host Capacity

For prefix mask length $/n$, usable addressing minus network ID and directed broadcast.

Usable Hosts = 2^(32 − n) − 2
Subnets formed = 2^(n − class_prefix)
Essential GATE '24, '21, '17
Formula #ALGO-01

Master Theorem Recurrence

Standard recurrence $T(n) = aT(n/b) + \Theta(n^k \log^p n)$ where $a \ge 1, b > 1$.

Compare: log_b(a) vs k
Case 1: Θ(n^(log_b a)) if log_b(a) > k
